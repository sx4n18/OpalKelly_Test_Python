# OpalKelly_Test_Python

This is the compilation of all the python scripts I have written to test the OpalKelly XEM7310 board.
Besides the testing scripts, I have also tried to include simple GUI applications based on PyQT6.

The scripts are organized in folders based on their functionality, such as "Basic Tests", "Advanced Tests", and "Utility Scripts".
Each script is well-documented with comments explaining its purpose and how to use it.
